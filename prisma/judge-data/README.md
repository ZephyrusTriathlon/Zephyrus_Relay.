# Public judge reference network

These synthetic CSVs are generated by `node scripts/generate-judge-data.mjs` without reading confidential competition data. They provide the same schema and network size (120 outlets, 60 vehicles, two depots) with deliberately simple values. They are not a copy of, or evidence of accuracy against, the supplied dataset. `SUPPLIED` in the existing database enum means imported reference rows; this directory is their documented provenance.

The deterministic scenario uses OUT004/OUT005, reefer truck VEH001, and 2025-01-02. OUT001 requires a van; VEH002 is a compatible reefer van. Calendar flags are synthetic (Sunday closed), covering 2024-01-01 through 2026-06-28. Use the authorized private dataset via `RELAY_DATA_DIR` for official-data verification, in a separate database; never switch datasets in an operational database.
